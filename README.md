# Nether Agriculture (Unofficial 26.x port)

This is an **unofficial port** of [Nether Agriculture](https://www.curseforge.com/minecraft/mc-mods/netheragriculture)
by **NetherDon** to Minecraft 26.x. It is not made or supported by the original author; please report problems
with this port here, not upstream.

- Original mod: [CurseForge (project 504384)](https://www.curseforge.com/minecraft/mc-mods/netheragriculture)
  and [GitHub (NetherDonMC/NetherAgriculture)](https://github.com/NetherDonMC/NetherAgriculture)
- Ported from upstream 2.1-beta2 (branch `dev/1.21`, Minecraft 1.21.1). Content, values, recipes, world
  generation and config defaults are kept as they were.

## Versions

| Minecraft | NeoForge | Fabric | Branch |
|-----------|----------|--------|--------|
| 26.1.2    | yes      | yes    | `26.1.2` |
| 26.2      | yes      | yes    | `26.2` |
| 26.3      | yes      | yes    | `26.3` |

Fabric needs Fabric API and Forge Config API Port. Cloth Config (config screen), Mod Menu and JEI are optional.
EMI support from the original is not included in this port.

## About
A **Minecraft mod** that adds **new crops** and **new food** to **the Nether**.
